## 2. 结构/姿态保真手段（按可靠性排序）

1. **CatVTON 局部重绘**（换装图的结构金标准）：只重绘服装区域，人体像素级锁定 → P2/P7 类换装图若 Qwen 版结构不过关，回退 V4 混合管线（本地 `ComfyUI_CatVTON_Wrapper` 已装）。
2. **多图指令锁定**（姿态图主力）：image1=锚定照（身份/体型）+ image2=姿态参考（骨架/构图），指令显式写"保持人物姿态、肢体结构、体型比例与参考一致"；多 seed 择优。2509+ 官方强化了人物编辑一致性，此路线正确。
3. **手部修复**（社区主流 = 检测→局部裁剪重绘→回贴）：SAM3/Impact Pack 手部检测 + Inpaint-CropAndStitch、HandFixer(FLUX-Fill)。本地均未装 → V10 自建 python 版：手部 bbox 裁剪 512px → Qwen-Edit 单独修手 → 拉普拉斯羽化回贴。仅在多 seed 仍出坏手时使用。
4. **重掷换 seed**：成本最低，V9 实测 13 张直出 9 张可用；V10 步数升 40 后预计再提升，继续作为第一手段。

## 3. DWPose 量化验收（新增，硬门槛工具）

- `comfyui_controlnet_aux` 已安装，含 DWPoseEstimator；onnx 权重（yolox_l.onnx 216MB + dw-ll_ucoco_384.onnx 134MB）从 hf-mirror 下载至 `models/annotators/`。
- 用 ComfyUI 嵌入式 python 直接 import controlnet_aux 跑 DWPose → 输出 18 关键点 → 与姿态参考图关键点比对：四肢角度差 <12°、躯干长度比差 <8%、关键点可见数 ≥16 为通过。
- 手部不依赖 DWPose（关键点太粗），以放大人工/judge 核验为准。

## 4. 真实感 prompt 规范（自研样本研读 + 社区确认）

- 写入：摄影语言（85mm/50mm、f 值、光比）+ 皮肤（natural skin texture, visible pores, subtle redness）+ 面料（print warping with fabric folds, chiffon translucency）+ 背景（seamless backdrop, clean gradient）。
- 禁用：smooth skin / perfect / flawless / magazine retouch 类催假词。
