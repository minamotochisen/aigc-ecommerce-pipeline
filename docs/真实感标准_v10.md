# V10 真实感标准（基于 48 张真实电商模特样本深度研读）

> 样本来源：必应图片真实电商摄影（影棚白底/室内景/街拍/行走/回眸/坐姿/手位合集），
> 下载 48 张 → 精选 27 张入库 `assets_v2/refs_real/selected/`。
> 用途：①生成 prompt 的写作标准 ②每张出图的验收对照 ③后续可选姿态参考。

## 一、人体结构硬标准（零容差项）

| 项目 | 真实样本规律 | 违例即不合格 |
|---|---|---|
| 头身比 | 影棚电商模特 7~8 头身；头顶到大腿根约 4 头身 | <6.5 或 >8.5 头身的拉伸感 |
| 手部 | 五指清晰分离、指节可见、自然微弯贴体侧或持物；手背有骨点凹陷与轻微泛红 | 并指/多指/指节糊成一团、蜡状平滑手背、手比脸小 |
| 手腕/脚踝 | 有明确骨点凹陷，宽度≈面部宽的 1/2.2 | 无凹陷的直筒腕、踝细到断感 |
| 腿部 | 膝盖有髌骨轮廓；小腿肚有肌肉曲线；承重腿直、放松腿微弯 | 轮廓波浪抖动、小腿直棍、双膝同形复制 |
| 脚/鞋 | 凉鞋带与脚背有明确前后遮挡+受光差；承重足鞋底有压缩变形 | 鞋带悬浮、脚在鞋里"融化"、左右鞋不同款 |
| 肩颈 | 斜方肌有斜度、锁骨有凹陷投影 | 锁骨高光呈白色涂抹带 |
| 重心 | 站姿重心腿同侧髋抬高，颈窝-肚脐-承重足近似一条垂直线 | 双腿均分重量的"立正假人" |

## 二、真实感来源（按贡献度排序）

1. **面料与印花受光**（最关键）：真实图印花/波点**随褶皱连续变形**，凸处变亮变大、凹处变暗压缩，半透面料下层可见腿色；生成图印花"平贴"在衣服上无褶皱联动 → 一眼假。
2. **皮肤质感**：真实图有毛孔颗粒、油性高光（鼻梁/锁骨/肩头/膝盖）、手背小臂轻微泛红、肤色不均匀；生成图肤色全程均匀如喷漆。
3. **遮挡关系**：裙摆压腿、手插兜、鞋带缠脚踝处必须有明确前后遮挡 + 投影；生成图交界处普遍"半透明涂抹"。
4. **背景光学**：影棚=无缝背景均匀渐变+脚下浅影；街拍=有连续景深虚化；生成图背景出现"水墨斑驳/马赛克"即假。
5. **发丝**：真实图碎发自然但每根有走向；生成图常见悬空断裂飞发。

## 三、摄影语言标准（prompt 写作规范）

- **影棚白底**：柔和顶光大平光 + 浅灰无缝背景，阴影只在脚边；85mm 等效、光圈 f/5.6~8 全身实焦；人物居中，上留白 8%、下 5%，占高 85%。
- **室内景**：窗光/环境漫射单主光，背景有自然明暗渐变；f/2.8~4 背景轻虚化。
- **街拍**：阴天或黄金时段侧逆光；50mm/f/2 景深压缩，背景人流虚化；行走方向留白。
- **站姿手位库**（真实样本归纳）：①自然垂放贴体侧（电商主图默认）②单手轻提裙摆侧缘 ③单手插兜 ④双手持包于胸腹前 ⑤双手叉腰（拇指朝前）⑥一臂上举过头。手指永远不指向镜头。
- **行走**：前腿落地、后腿蹬直近似一条线（猫步）；双臂前后自然摆；视线看行进方向。
- **回眸**：背对镜头、上身扭转 60-90°，仅头转回；撑物手臂手指张开承重。
- **坐姿**：坐椅面前 1/2，双腿交叠或前后错位，脚尖下绷；一手撑椅面承重。

## 四、对照诊断（V9 现版 vs 真实样本，2026-08-30）

**P2 换装图（豆包裙）**
- [质感] 大幅印花无褶皱形变，色块平贴 ← 最严重
- [皮肤] 手臂/腿肤色均匀无油光、无泛红过渡
- [背景] 灰白墙面大面积水墨斑驳纹理（假背景）
- [结构] 左手手指并指感、右手腕-手背过渡生硬（待放大复核）
- [轮廓] 右小腿波浪抖动；发丝悬空断裂（右肩外）
- [对比] BEFORE 锚定照为真实照片，肤色/布料质感差距一目了然

**P5 姿态宫格（六姿态）**
- 行走格：背景树丛马赛克（已知问题），裙下双腿轮廓含糊、脚部不清
- 回眸格：撑树枝手臂与枝叶融合异常，指部难辨
- 3/4站格：裙摆下缘与双腿交界半透明涂抹；承重脚鞋形可疑
- 叉腰格：左腕有金色异物混入；裙摆不对称摆动
- 站立格：最干净，但手腕细得夸张、手部偏小偏糊
- 共性：六姿态肤色均匀无血色；手/脚/腕细节全面弱于真实样本；波点面料无褶皱联动

**结论**：V9 的结构（骨架级）大体成立，但"真实感差距"集中在 **面料受光、皮肤质感、手脚细节、遮挡关系、背景光学** 五项 —— 与本次调研结论一致，全部可通过 prompt 重写 + 参数加强 + 重掷解决。

## 五、落地要求（进入 V10 生成清单）

1. prompt 必须包含：摄影语言（机型/焦段/光比）+ 皮肤质感词（natural skin texture, visible pores, subtle redness on knuckles）+ 面料物理词（print warping with fabric folds, chiffon translucency, soft caustic shadows）+ 背景词（seamless paper backdrop, clean gradient）。
2. 禁用词自查：不写 smooth skin / perfect body / magazine retouch 等催生假感的词。
3. 每张出图按第一节硬标准逐项验收 + 与本库 selected/ 同姿态样本并排比对。
4. 手部特写复核：任何手在画面中的图，放大 2x 核对五指。
