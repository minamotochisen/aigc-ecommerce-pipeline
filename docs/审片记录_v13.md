## 关键发现(进评测页/迭代总结)

1. **5B TI2V 纯文生视频不可用**:同工作流去掉 start_image 后输出与 prompt 完全无关,判定 TI2V-5B 为 I2V 中心模型,文本仅驱动运动而非内容——"文生视频"交付由 14B 路线或云端承担(与社区认知一致)。
2. **步数 A/B**:12 步 149s vs 20 步 203s,20 步质感更优但尾帧出现闭眼;主力镜头 20 步、B-roll/变体可用 12 步。
3. **运动幅度边界**:5B 对"走/迈步"执行保守,真实位移弱;姿态参考里已有的步态(行走照)反而产出最自然的行走动态——**图像先验强于文本驱动**。
4. **幻觉手势是 5B 最大翻车点**:托脸(好)、掏纸巾打喷嚏(坏)、凭空皮包(坏)、抬手鬼影(坏)——静止类镜头 prompt 需显式写死"双臂下垂/无手势"。
5. FLF2V 14B / Lightning A14B 实验数据见第二轮。

**过程判负记录(根因修正)**:l14b/FLF 曾在动态/静态两种显存模式下均"采样启动即抛 OSError Errno 22"(3 次复现);对照实验证明真正相关项是**服务启动方式**——PowerShell Start-Process(-RedirectStandardOutput)拉起的进程必崩,python subprocess.Popen(追加日志句柄)启动后正常(l14b 717s 成片复证)。Windows 句柄继承差异破坏权重 mmap 为最可能根因。
