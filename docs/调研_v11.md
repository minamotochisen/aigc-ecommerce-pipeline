# V11 调研：针对 R0 问题的方法与解法（2026-08-31）

调研来源：Qwen 官方模板/博客、HF 讨论区、Reddit r/StableDiffusion、RunComfy、ComfyUI 社区、中文电商 AI 商拍实践文章、pixelpanda 比例指南等。

## 1. 采样参数（对应根因 E/A/B 整体质量）

- **官方 2511 模板基线：40 步 / CFG 3.0 / euler / simple / denoise 1.0**（本地模板 widgets_values 实测确认）。V10 期间"必卡死"是 nvlddmkm 驱动故障期表现，重启后自愈；2026-08-31 晚实测 40 步 364s/张 稳定。已把 STEPS 20→40、cfg 4.0→3.0。
- HF 官方 prompt 指南：终版用原生 25-40 步 + CFG≈3；多图参考时 true CFG 可能引入伪影（参考内容相关），若出现则用低 CFG 或 Lightning LoRA。
- 多图参考顺序：**身份照（脸部清晰）放 image1**，服装等放后续槽位——与现有管线一致。

## 2. 人脸结构畸形 + 身份漂移（根因 A）

- RunComfy（Qwen-Edit-2511 likeness 指南）：主输入不是脸部特写时，**把裁剪的脸部特写作为额外身份参考图传入**，给模型更干净的身份信号。
- Hires-fix 思路（社区）：对成片**低重绘幅度（~0.3-0.4）局部重绘**可在不改身份的前提下锐化五官。
- 2511 官方博客主打"character consistency"，但多轮编辑后人脸仍会漂移（GitHub issue #88）——所以每轮修完要重新与锚定照比对。
- **落地：新增 facefix 模式**——从锚定照裁脸 + 从成片裁脸（放大到 768px），双图输入 face 一致性重绘（低 denoise 不行，KSampler denoise 1.0 是本管线唯一实测稳定路径；改为"整脸区域裁剪-重绘-羽化回贴"，与 handfix 同框架），prompt 锁"同一张脸/五官结构/眼镜/妆容"，配 21 点面部 DWPose 人工裁片核验。

## 3. 身体比例（根因 C：头小腿长）

- pixelpanda 比例基准：**电商时尚 7.5-8 头身；生活类 7-7.5**；常见 AI 失败=头大漂移（macrocephaly）与**四肢比例不一致**；本作反常为"头偏小+下肢拉长"（豆包 R0 各页一致指出）。
- prompt 层：加"photorealistic, not stylized"防插画化拉长；"头部与身体比例符合真实人体，七头身，自然肩腰比"。
- **校准层（关键）**：prompt 对比例收效有限（社区共识）——用 DWPose 实测**锚定照真人头身比/躯干腿长比**作为硬阈值，生成图超界即重掷。
- 修正层：头部图层面缩 3-5% 无痕（cap 8%），仅在重掷 3 seed 仍超界时使用。

## 4. 皮肤蜡质塑料感（根因 D）

- prompt 词：visible pores / natural skin texture / subtle blemishes / subsurface scattering / 自然油光（中文对应写入 LOCK）。
- 工作流层：皮肤区域低 denoise(0.3-0.5) detail 重绘注入纹理；后处理层：**微颗粒 + 微对比**（PIL 可实现，均匀轻量避免"磨皮反转"过猛）。
- 负面词已有"蜡质塑料皮肤/皮肤过度光滑"，40 步+新 LOCK 后观察，必要时做 skin 裁片 pass。

## 5. 印花碎裂（根因 E）

- R0 显示碎花裙印花"方块马赛克碎裂"为 20 步+91830 seed 的产物；40 步+CFG3 重掷 + 多 seed 择优是主修复；波点裙（P5/P6）印花"总体完整仅局部错乱"佐证模型能力够，问题在采样预算与 seed。
- prompt 强调"印花图案连续完整，随褶皱连续形变，凸处受光凹处转暗"（已有 REALISM 段，保留）。

## 6. 背景方案（用户要求：热门商业化模特样本背景）

2025-2026 热门电商女装摄影背景（多源交叉）：
| 风格 | 关键词 | 用途 |
|---|---|---|
| 极简影棚无缝 | 中性白/浅灰无缝纸、柔和顶光、浅景深 | 主图/封面（最主流） |
| 奶油/莫兰迪室内 | 奶油色墙面、原木、窗帘柔光 | 连衣裙/温柔风 |
| 法式轻奢室内 | 大理石、复古家具、落地窗 | 轻奢 |
| 暗调电影感 | 近全黑背景、戏剧光 | 高定质感 |
| 街拍实景 | 城市/咖啡馆外景、浅景深 | 种草/潮流 |

- 已按 6 类 query 搜集 21 张样本入 `assets_v2/refs_bg/`（seamless/cream/french/arch/studio_beige），供 prompt 复刻与 judge 对标。
- **背景决策**：P1/P2 影棚主图→纯色无缝（修"斑驳涂抹"）；P3→奶油风极简室内（柔和窗光，光线软、与影棚人物光差异小）；P4→街拍保留但改阴天柔光+浅景深（R0 光影割裂根因是硬阳光 vs 影棚柔光）；P5/P6 各姿态格背景统一浅灰/奶油无缝（R0 指出户外格光影割裂致命）。
- **光影适配**：掩膜人物像素锁定的前提下，对人物层做 Lab 空间亮度/色温轻量匹配（±10% 内），并**把页面文案改为"背景替换+人物光影适配"**，不再宣称"零重绘"。

## 7. 文案与信息一致性（根因 H/I/J——低成本高收益）

豆包 R0 判定 4 处图文矛盾【致命】：P2"姿态构图保持"、P3/P4"人物像素锁定零重绘/换景不伤人"、P5"身份高度一致/无遮罩拼接"、P10"全程无人值守"、P11"做到能直接上架"slogan、P9"走秀"标题+无动态预览、**P11 邮箱 [邮箱已隐去] 为手机号误写（无法收信）**。
原则：**每句技术宣称必须与样图实测对齐**；缺陷就近小字标注；已实现/未来规划分区。

## 8. 评审介质校准（根因 L）

110dpi 页图使手脚细节约 30px，豆包系统性放大判罚（真人锚定照小图也被判"畸形"）。复评改用 **150dpi 页图**，并在送评说明中注明"页面为 PDF 150dpi 渲染，源图内嵌 2600px"。
